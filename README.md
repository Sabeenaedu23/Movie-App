# 🎬 Movie App – Front-End Development Project

## 📌 Project Overview

The Movie App is a responsive web application developed using HTML5, CSS3, and JavaScript. It provides a clean and interactive interface for users to explore and discover movies.

This project demonstrates my front-end development skills, with a focus on responsive design, user interaction, and JavaScript functionality.

## ✨ Key Features

- Modern and user-friendly interface
- Responsive design for desktop, tablet, and mobile devices
- Interactive movie browsing experience
- Dynamic content handling using JavaScript
- Clean layout and structured components
- Smooth user interactions

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling and responsive layout |
| JavaScript | Interactive functionality |

## 📱 Responsive Design

The application is designed to provide a consistent user experience across:
- Desktop computers
- Laptops
- Tablets
- Mobile devices
